针对Java字节码工程和逆向工程，这里整理了一份主流工具清单，并按功能进行了分类，方便你根据需求选用。

🔎 全能逆向套件 (瑞士军刀)
这类工具功能全面，集成了反编译、编辑、调试等多种功能，是进行Java逆向分析的利器。

Bytecode Viewer (BCV)：一款广受欢迎的开源图形化工具。

核心功能：集成6种反编译器（如CFR, Procyon, FernFlower, JD-GUI等）、3种反汇编器、2种汇编器及APK转换器。支持JAR、APK、CLASS等多种文件格式。

特色：内置Java编译器，可修改后回编译；支持插件系统；具备恶意代码扫描API。

Recaf：另一款功能强大的JVM逆向工程工具包，专注于字节码的检查与修改。

JByteMod-Remastered：现代化的Java字节码编辑器。

核心功能：支持字节码编辑、反编译、重编译。提供图形化的字节码查看器和控制流图（Control Flow Diagram）。支持JAR、APK和CLASS文件。

特色：拥有常量池编辑器（Constant Pool Editor）和插件系统。

🔧 专业反编译器 (将字节码转换为Java源码)
当需要高质量地将class文件还原为可读的Java源代码时，这些工具是首选。

JD-GUI：经典的图形化反编译器。它是独立的图形界面程序，支持浏览整个JAR文件并跳转源码。

CFR：一款优秀的命令行反编译器，以处理现代Java特性（如lambda表达式）而闻名。

FernFlower：由JetBrains开发，是IntelliJ IDEA内置的反编译器，同样支持命令行使用。

Procyon：Twitter开源的反编译器，也是一套Java元编程工具集。

JADX：强大的DEX到Java的反编译器，尤其适用于Android APK分析。

命令行工具：JDK自带的javap命令可以查看类的字节码信息。

✍️ 字节码编辑器与操作库 (直接修改字节码)
如果需要进行底层操作，比如直接编辑字节码指令或动态生成类，可以使用这些库和工具。

ASM：业界标准的Java字节码操作与分析框架。可用于直接以二进制形式修改现有类或动态生成类。

BCEL (Byte Code Engineering Library)：另一个经典的字节码工程库，提供了分析、创建和操作Java类文件（.class）的便捷方式。

Javassist：提供更高级别的API，允许你通过源代码级别（Source-level）的方式来操作字节码，对开发者更友好。

🚀 运行时与JVM级工具 (动态分析与调试)
这类工具用于分析正在运行的Java程序，实现动态调试、监控和方法钩子等。

Java Process Inspector：一个实时JVM分析工具包。

核心功能：支持实时检查、反编译、分析和修改运行中的JVM应用。

特色：具备强大的反混淆工作区（Deobfuscation workspace），可创建本地命名映射来帮助理解混淆代码。支持导出Tiny v2, ProGuard等多种映射格式。

JVM Inspector：一款x64dbg调试器插件，使x64dbg能够感知JVM。

核心功能：提供类浏览器、字节码反编译器、对象检查器、线程栈查看等。

特色：强大的Hacking工具包，支持设置Java方法断点、内存补丁、字段值冻结（类似Cheat Engine）、内存和字符串扫描。特别地，它包含对Minecraft的专用分析功能。

🌐 在线工具 (无需安装)
Slicer：一款现代的Java逆向工程Web工具。它完全在浏览器中运行，无需下载安装。支持CFR, Procyon等反编译器和反汇编器，并提供控制流图（CFG）可视化。适合快速查看类文件。

📚 类库与框架 (二次开发)
Kapteyn：一个用于逆向工程Java类文件和JAR的库。它包含一个精确的类文件解析器和现代化的字节码反编译器。

全能型选手：首选 Bytecode Viewer (BCV)或 Recaf。它们集成了多种反编译器，功能强大，能满足绝大多数逆向需求。

高质量反编译：如果需要将字节码还原为最清晰、准确的源码，可以单独使用 CFR、FernFlower 或 Procyon 等专业反编译器。JD-GUI 则提供了便捷的图形化操作。

动态分析与调试：当需要分析、修改正在运行的Java程序时，Java Process Inspector 和 JVM Inspector 这类运行时工具是绝佳选择。

底层字节码操作：如果是进行底层开发，如创建新的编程工具或进行复杂的字节码增强，ASM 和 BCEL 这类库是基础。

快速查看：只是想快速查看一个类文件的内容，无需安装任何东西，直接使用在线工具 Slicer 即可。

Aqui está a lista completa e detalhada das melhores ferramentas para engenharia reversa de arquivos JAR, CLASS e até APK, com foco em descompiladores, editores de bytecode, carregadores (loaders) e ferramentas de análise em tempo de execução, tudo traduzido para o português.

🔎 Suítes Completas (Canivetes Suíços)
Estas ferramentas reúnem descompiladores, editores e depuradores em uma única interface.

Bytecode Viewer (BCV) – Uma das ferramentas open-source mais populares.

Funcionalidades: Integra 6 descompiladores (CFR, Procyon, FernFlower, JD-GUI, etc.), 2 desmontadores e 2 montadores. Suporta JAR, APK, CLASS e até DEX.

Diferenciais: Possui compilador Java embutido (edite e recompile na hora), sistema de plugins e scanner de vulnerabilidades/malware.

Recaf – Outra ferramenta moderna e poderosa focada na inspeção e modificação de bytecode JVM. Possui interface intuitiva e suporte a plugins.

JByteMod-Remastered – Editor gráfico de bytecode moderno.

Funcionalidades: Visualização de bytecode, gráfico de fluxo de controle (CFG) e editor do Pool de Constantes (Constant Pool).

Diferenciais: Permite editar, recompilar e salvar as alterações diretamente no JAR.

🔧 Descompiladores Dedicados (Bytecode → Código Fonte)
Use estas ferramentas quando precisar da melhor qualidade possível de código Java reverso.

JD-GUI – O clássico descompilador gráfico. Perfeito para navegar por pacotes e classes dentro de um JAR com um clique.

CFR – Descompilador de linha de comando altamente recomendado. Lida excepcionalmente bem com código moderno (lambdas, expressões em switch, etc.).

FernFlower – Descompilador da JetBrains (usado internamente pelo IntelliJ IDEA). Também funciona via linha de comando.

Procyon – Descompilador open-source do Twitter, parte de um conjunto maior de ferramentas de metaprogramação.

JADX – Focado em Android, descompila arquivos DEX para Java, mas também funciona muito bem com JARs que contenham código Android.

Dica de linha de comando: O próprio JDK vem com o javap -c -v NomeDaClasse.class para visualizar o bytecode bruto (sem descompilar para Java).

✍️ Editores de Bytecode e Bibliotecas de Manipulação
Para modificar a lógica em baixo nível (instruções invokevirtual, goto, etc.) ou gerar classes dinamicamente.

ASM – O framework padrão da indústria para manipulação de bytecode Java. Permite ler, modificar e gerar arquivos .class no nível binário. É a base de muitas ferramentas de instrumentação.

BCEL (Byte Code Engineering Library) – Biblioteca clássica da Apache para análise e criação de bytecode. Oferece uma API estruturada para manipular classes.

Javassist – Oferece uma API de alto nível que permite modificar o bytecode usando código fonte (ex: CtClass e CtMethod), sendo muito mais amigável para iniciantes.

🚀 Ferramentas de Tempo de Execução (JVM ao Vivo)
Perfeitas para análise dinâmica, hooking de métodos e depuração de aplicações rodando.

Java Process Inspector – Um toolkit completo para análise de JVMs em tempo real.

Funcionalidades: Inspeção, descompilação e modificação de aplicações em execução.

Diferencial: Possui um espaço de trabalho de desofuscação (Deobfuscation Workspace) que permite criar mapeamentos de nomes (ex: a.b.c → minhaClasse) e exportar nos formatos Tiny v2, ProGuard, etc.

JVM Inspector – Plugin para o depurador nativo x64dbg, que adiciona consciência sobre a JVM.

Funcionalidades: Navegador de classes, descompilador de bytecode, inspetor de objetos e pilhas de threads.

Diferencial: Kit de ferramentas de hacking com suporte a breakpoints em métodos Java, patching de memória, congelamento de valores de campos (similar ao Cheat Engine) e análise dedicada para jogos (ex: Minecraft).

🌐 Ferramentas Online (Sem instalação)
Slicer – Ferramenta web moderna de engenharia reversa Java. Roda inteiramente no navegador. Suporta os descompiladores CFR e Procyon, além de exibir gráficos de fluxo de controle (CFG). Ótimo para uma análise rápida.

Kapteyn – Biblioteca moderna para parsing preciso de arquivos .class e descompilação de bytecode. Ideal para quem quer construir ferramentas customizadas.

🛠️ Suítes Completas de Desofuscação
Estes projetos são os mais abrangentes, com o objetivo de reverter a ofuscação de diversos ofuscadores comerciais e de código aberto.

java-deobfuscator/deobfuscator: É o projeto mais conhecido e ativo, frequentemente chamado de "the real deal". Ele suporta ofuscadores comerciais como Zelix Klassmaster, Stringer, Allatori, DashO, DexGuard e outros.

Funcionalidades: Oferece detecção automática do ofuscador utilizado e diversos "transformers" para reverter técnicas como ofuscação de string e reflexão.

Como usar: Possui uma versão com interface gráfica (GUI) e pode ser usado via linha de comando com arquivos de configuração YAML.

Diobf/Deobfuscator: Um desofuscador moderno e modular, também conhecido como Diobfuscator. Está em desenvolvimento ativo.

Funcionalidades: Permite selecionar quais "transformers" aplicar ao arquivo JAR ofuscado.

Como usar: Projetado para ser executado a partir de uma IDE (ex: IntelliJ), configurando o arquivo Bootstrap.java. Requer Java 17 para compilar e Java 8 para o sandbox.

threadtear (por loerting): Uma "suíte multifuncional de desofuscação Java", ideal para uma abordagem mais ampla e combinada.

🧩 Ferramentas Especializadas e Bibliotecas
Projetos com um foco mais específico ou que servem como base para construir suas próprias ferramentas.

katana-project/poke: Uma biblioteca Java (com CLI) que realiza normalização de bytecode e desofuscação genérica.

Funcionalidades: Funciona como um "wrapper" em torno do núcleo do ProGuard, configurado especificamente para otimização, sem a necessidade de regras -keep.

Como usar: Pode ser usada como biblioteca em seus próprios projetos ou via linha de comando com opções como --optimize e --inline.

Stanislav-Povolotsky/jddlab: Um laboratório de descompilação e desofuscação Java empacotado em uma imagem Docker.

Funcionalidades: Reúne todas as ferramentas necessárias em um ambiente isolado, minimizando riscos e simplificando a instalação.

Como usar: Basta ter o Docker instalado e usar o comando jddlab para executar as ferramentas no container.

GraxCode/threadtear: Uma suíte de ferramentas de engenharia reversa Java, com foco em desofuscação.

🗺️ Ferramentas de Remapeamento (Mapping)
Mapping-IO: Uma biblioteca pequena e eficiente para trabalhar com arquivos de mapeamento de desofuscação.

Lorenz: Uma representação de mapeamentos de desofuscação para JVM.
