# Street runner

One target, one order. `decrypted=true` only when the crypto stage validated a cipher. An observe dump is `runtime_dump` when `.text` Shannon stays at or above 4.

| Tool | What it does |
|---|---|
| `street-pipeline.bat <file> [out]` | classify, complete, pdata, auth name list. No spawn. |
| `street-observe.bat <exe> [out] [seconds]` | same, then no-debug RPM if the ranking is Themida, VMProtect, or an empty `.text`. |
| `street pdata <image> --out <dir>` | `FUNCS_PDATA.txt`. Raw PE, or VA-linear `image.bin`. |
| `street crypto <file> --out <dir>` | ranking, protect surface, auto-solve. |

`live-dump` stays a separate command. The runner does not call it. Auth output is the name list in `07-AUTH.md`.
